\section{Implementation}
\label{sec:Implementation}
%% ==============================

This section describes the final implementation of the dynamic Multi-Armed Bandit (MAB) hyper-heuristic system. It explains the software stack, the interprocess communication, low-level heuristic pool and outputs.

\subsection{Technology Stack and Software Architecture}
\begin{itemize}
    \item \textbf{Python Execution Engine (v3.11.7):} This is the entry point to the scheduler that houses the multi-armed bandit decision algorithms, workload trace ingestion module, and the reward function. It uses \texttt{NumPy} and \texttt{SciPy} for statistical operations and \texttt{Pandas} for trace parsing.
    \item \textbf{Java Simulation Engine (OpenJDK 21 / CloudSim Plus v7.3.0):} Acts as the cloud simulation environment. CloudSim Plus core classes were extended to support low-level heuristic instantiation and I/O streams
\end{itemize}

\subsection{Standard I/O Inter-Process Communication Pipeline}
In order to reduce the overhead of the spawning a new process for every CloudSim instance, we make use of inter-process communication to create a singular data stream between the Python control plane and the Java simulation engine.

The Python program launches the Java instance as a managed subprocess that receives a JSON payload containing the batch index and task specifications.

The Java application holds a stream reader that parses incoming JSON records asynchronously, which then executes the batch across the virtual machine pool.

\subsection{Low-Level Heuristic Pool Implementation}
The low-level heuristic pool is implemented inside the Java simulation core under a unified strategy interface, with nine distinct scheduling routines being implemented:
\begin{enumerate}
    \item \textbf{List-Based Schedulers (HEFT, PEFT, Min-Min, Max-Min, Sufferage, HEFT-TD):} Custom task prioritization routines construct directed acyclic graph (DAG) task ranks and evaluate expected finish times across heterogeneous VM capacity matrices on the fly.
    \item \textbf{Deterministic Baseline (Round-Robin):} Sequentially maps incoming cloudlets to active VMs to establish a dynamic baseline for performance normalization.
    \item \textbf{Local Search and Meta-Heuristics (Simulated Annealing, HGHHC):} Algorithmic state models execute local schedule permutations HGHHC combines the Henry Gas Solubility Optimization and the Harris-Hawks Optimization methodologies into a singular algorithm that runs multiple evaluations within given time slots.
\end{enumerate}

\subsection{Energy, Carbon Footprint, and Cost Modeling}
In order to accurately measure the trade-offs, some CloudSim classes had to be modified, as well as creating new modules:
\begin{itemize}
    \item \textbf{Monetary Cost Model:} With the help of AWS billing API, we were able to simulate resource pricing. Each VM instance incurs a fixed per-second compute rate based on its allocated processing capacity (MIPS) and memory profile, following tier-based provider pricing schemes.
    \item \textbf{Dynamic Power Model:} Power consumption $P(u)$ is calculated as a function of CPU utilization:
    \begin{equation}
    P(u) = P_{\text{idle}} + (P_{\text{max}} - P_{\text{idle}}) \times u
    \end{equation}
    where $P_{\text{idle}}$ represents the VM's power consumption while idle, and $P_{\text{max}}$ represents peak power under full load.
\end{itemize}

\subsection{Non-Stationary Infrastructure Fault Injection}
A fault injection module was implemented in the Python environment. The purpose of this module is to simulate infrastructure failure, as well as monitoring and evaluation how each bandit algorithm withstands a sudden change in VM capacity.

\subsection{Generated Outputs and Data Transformation}
The execution pipeline produces outputs for anaylysis:
\begin{enumerate}
    \item \textbf{Raw Trace Log Stream:} Logs per batch that contain details such as the heuristic used, makespan, reward, etc.
    \item \textbf{Aggregated Seed Benchmark Dataset:} CSV files for each arm under each of the bandit algorithms.
\end{enumerate}
